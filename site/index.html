Keep Claude Code.
Switch your models.

NeoSwitch lets Claude Code run on Gemini 4 Neon. Your commands, permissions, tools, skills, MCP servers and hooks stay exactly as they are; a small local proxy translates requests for the model behind them.

Only the model changes

Claude Code still owns the session, permissions, tool execution and CLAUDE.md. NeoSwitch sits on loopback and speaks the Anthropic Messages API on one side and Gemini on the other.

Honest compatibility

What works, what is partial and what is missing is listed below. No silent fallback.

Get started

Requires Claude Code and Go (the plugin builds its binary on first use). For Antigravity OAuth you also need the official agy CLI on your PATH.

Install the plugin

Inside Claude Code:

claude
> /plugin marketplace add yldm-ai/neon-switch
> /plugin install neoswitch@neoswitch

Sign in and enable routing

In the project that should use Neon. To use a Gemini API key instead, set it under /plugin → neoswitch → Gemini API key and run /neoswitch:on.

claude
> /neoswitch:login

Restart and check the route

Reopen Claude Code in that project. The session header may still show a Claude model label; the status command shows the real upstream.

claude
> /neoswitch:status
  NeoSwitch ... -> gemini-4-neon

Choose a credential path

Run neoswitch doctor on any path. It looks the model up, runs a one-line generation and names the failing step if something is wrong.

Antigravity terms. The Google Antigravity Terms of Service (section 6) treat accessing Antigravity through third-party software as a breach, and Google may suspend or terminate the Antigravity and Gemini CLI accounts involved. Routing Claude Code through Antigravity OAuth falls under that rule. Use it only if you accept that risk for the account you sign in with; otherwise use a Gemini API key or Vertex AI.

Compatibility

How well Claude Code's features work depends on how well the model follows its tool protocol. This has been exercised in everyday coding use, not by an automated end-to-end suite.

CapabilityGemini API / Vertex AIAntigravity OAuth (ACP)
Streaming textSupportedSupported
Tool calls, incl. parallelNative Gemini function callingPartial: tool-call JSON arrives whole, not streamed
Multi-turn tools, /resumeSupportedSupported
ImagesSupportedWhen agy offers image input
PDFsSupportedNot supported
/effortNot applied yetMapped to agy's thought level
Token usage, count_tokensReported; estimated on the Developer APIReported, incl. ~14k tokens of agy instructions

Not supported on either path: server tools such as web search and code execution, URL image and document sources, and Claude thinking blocks. Full contract in docs/protocol-contract.md.

Plugin commands

Routing changes apply to new sessions; the current session keeps its connection.

/neoswitch:loginSign in with Antigravity OAuth and enable this project's route
/neoswitch:onEnable routing for this project
/neoswitch:statusShow the route and daemon state
/neoswitch:offDisable routing for this project

Prefer a standalone binary? Builds for macOS, Linux and Windows are on the Releases page, and neoswitch serve works with any Anthropic-compatible client.
